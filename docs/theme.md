# 테마

- 상단의 다크 모드 / 라이트 모드 버튼 또는 `T` 키로 전환합니다.
- 기본값은 라이트 모드입니다. `kobong-site-template`과 같은 `kobong-theme` localStorage 키를 사용합니다. 동일한 도메인·포트에서는 선택이 공유됩니다.
- 스타일을 읽기 전에 저장된 테마를 복원합니다. 저장소 사용이 차단되어도 현재 페이지의 전환은 동작합니다.
- 검색 입력·한글 조합 중 또는 대화상자가 열린 상태에서는 `T` 단축키를 실행하지 않습니다.
- Python/FastAPI와 GitHub Pages 모두 같은 정적 파일을 사용합니다. 테마 변경에 서버 API는 필요하지 않습니다.

검증: `node --test tests/theme.test.mjs`로 초기 복원, 다중 버튼 동기화, 저장소 차단, 입력 중 단축키 보호, 다른 탭의 변경 반영을 확인합니다. 브라우저에서 모바일 레이아웃과 실제 색상은 별도 확인이 필요합니다.
